Rule 5 · The pass

Nothing leaves the kitchen without a taste test

The kitchen

Work in progress

Half-done dishes stay back here. Guests never see them.

Taste test

Pass, or back to the stove

The dining room

Finished work only

Only dishes that passed the test are ever served.

A cook can’t just say “done”. The test decides.

Rule five, and maybe the most important one. In a good restaurant there’s a counter between kitchen and dining room called the pass, where the head chef tastes every plate. Ours works the same way. When a cook says “I’m done”, that’s not enough: an automatic taste test runs first. Only if it passes is the dish served, meaning the finished work is added to the real product. If it fails, the cook gets it back and has to fix it. So the dining room, the version people actually use, only ever contains finished, checked work. Half-done things never leak out.
