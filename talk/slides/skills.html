Which model should take which task?

The task declares a difficulty

LevelMeaning
1Mechanical: smallest model
2Normal work (the default)
3Hard: a strong model
4The best model available

Escalate on failure

Each failed release or redo raises the level by one.

Reserve scarce models

The strongest model waits for the hardest tasks, but the critical path never waits long.

Deterministic, not self-assessed

LLMs judge their own ability poorly. The runner decides.

This is the next task on our own board, so it's a design, not a result yet. Agents are not equal: some teammates have access to stronger models than others. Rather than having agents judge whether a task suits them, which LLMs do badly, each task carries a difficulty, the runner picks a model per task, and failures escalate: a task that failed on a mid-size model runs on a stronger one next. The scarce top model is reserved for the hardest work without letting the critical path starve.
