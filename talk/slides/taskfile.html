## Goal
Match tasks to models...
## Acceptance criteria
- [ ] tasks have difficulty 1-4

Front matter is state

Only the tool writes status and owner.

deps form a graph

next lists ready tasks, most-blocking first.

Criteria are the contract

Checkable, 30 to 90 minutes of work, tests included.

This is a real task from the project. Front matter holds the state; agents never edit status or owner by hand, the tool does, so every transition is a well-formed commit. Dependencies form a DAG and "next" sorts ready tasks by how much they unblock. The body is for humans and agents alike: a goal and checkable acceptance criteria. Task size matters a lot: 30 to 90 minutes for one agent.
