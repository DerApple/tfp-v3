Mechanics · done

Main only ever holds finished tasks

1 · Merge main

Pick up what others finished meanwhile.

2 · Run the check

.taskcheck: lint and tests, on the merged result.

3 · Mark done, push

Code and status land in one go.

Agents never push. A deny rule in the agent settings enforces it; done pushes for them.

Check fails? Nothing is pushed. Fix it and run done again.

Done is the gate. It merges the latest main first, because a clean merge can still break things when another task renamed something you call. Then it runs the project's check on the merged result, and only if that passes does it mark the task done and push. Agents are technically forbidden from pushing themselves. The result: main is always a set of finished, checked tasks, and it can be published to the real repos at any time.
