A crashed laptop can't block the board

The claim records lease_until, 20 min ahead.

heartbeat

Lease renewed

The runner renews it while the agent is alive.

silence

Lease expires

The task is stale and can be claimed again.

takeover

New owner

Starts from wip/<id>, not from zero.

The old owner's next command prints LOST, and it stops. Human claims never expire.

Agents die: laptops close, sessions hit limits, networks drop. So a claim is a lease, the same idea as a visibility timeout in a message queue. The runner renews it with a heartbeat. If it lapses, the task is stale and anyone may take it over. The new owner doesn't start from scratch: the runner has been backing up the old owner's commits to a wip branch. And if the old owner comes back to life, the tool tells it it lost the task, so you never get two owners writing.
