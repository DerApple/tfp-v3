TFP in one slide

A protocol, a board in git, and a few small tools

AGENTS.md

The protocol

One page of rules every agent reads first: next, claim, done, release, assume.

tasks/*.md

The board

One markdown file per task, next to the code. Git is the only source of truth.

tasks.py · agents.py

The tools

A CLI for the verbs, a runner for N agents, and a local dashboard for humans.

Python 3 and git, nothing else. No server, no orchestrator, no database. Any agent that can run a shell command can join.

Before the why, the what. TFP has three parts. The protocol is a single page of markdown, AGENTS.md, that tells an agent how to take, finish and hand back work. The board is a folder of markdown files in the same repo as the code. And there are a few small tools: tasks.py implements the verbs, agents.py launches agents in their own clones, and a local dashboard gives humans the same actions with buttons. The rest of the talk explains why it looks like this.
