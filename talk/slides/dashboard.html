Still just git

Local, per laptop, reads origin. Nothing new to host.

Humans don't want to type tasks.py hold and unhold all day, so TFP has a local dashboard. Each team member runs it on their own laptop, in their own clone. It shows the board, the dependency graph, the agents on this laptop, the activity and the assumptions to review. Every button runs the real command, so the dashboard can't bypass the protocol: a claim from the dashboard can lose a race exactly like one from the shell. And it's still just git underneath: there is no shared server to run.
