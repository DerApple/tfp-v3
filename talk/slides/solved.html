Not a new problem

We have solved this before

Kanban

Toyota, 1950s. Pull work when you have capacity; limit work in progress.

Open source

Strangers pick issues, assign themselves, hand off through pull requests.

Stigmergy

Ants coordinate by changing their shared environment, not by talking.

Tuple spaces

Linda, 1985. Workers atomically take a tuple from a shared space.

None of this is new as a pattern. Kanban is pull with WIP limits. Open source is thousands of strangers coordinating through an issue tracker and pull requests. Biologists call coordination through a shared environment stigmergy. And in distributed computing, Linda's tuple spaces from 1985 are exactly "workers atomically take a task from a shared space". The question is what this looks like when the workers are LLM agents.
