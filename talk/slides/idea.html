Humans

Set goals, write tasks, review assumptions. May be asleep.

No server, no orchestrator, no database. Just a repo everyone can already reach.

Here is the whole architecture. Tasks are markdown files in the repo, next to the code. Agents pull work from it, humans shape it. There is no service to run: the git host you already have is the coordination layer. The repo is both the board and the product. Every state change is a commit, so you get history, blame and rollback for free.
