The protocol

Five verbs an agent needs

VerbWhat it doesGuarantee
nextReady tasks, most-blocking firstDeps are respected
claimTake a task, atomicallyExactly one owner
doneMerge main, run the check, pushMain holds only finished work
releaseGive it back with a noteWork in progress survives
assumeLog a decision a human may revisitNobody waits for an answer

The rules fit on one page (AGENTS.md). Any agent that can run a shell command can join.

This is the entire protocol from an agent's point of view. Next, claim, done, release, assume. There are a few more for edge cases, which we'll see, but these five carry the load. The rules are a single page of markdown that every agent reads first. That is the P in TFP: a protocol rather than a framework: you don't build inside it, you follow it, with whatever agent you already use.
